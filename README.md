# Agro Forte, Futuro Sustentável 🌾🚀

Este é um projeto de site multipáginas focado no desenvolvimento do agronegócio moderno em sinergia com a preservação ambiental. O objetivo da plataforma é demonstrar de forma visual, interativa e prática como a tecnologia e a sustentabilidade andam juntas no campo.

## 📱 Sobre o Projeto

O site aborda o equilíbrio entre a alta produtividade agrícola e a conservação da natureza, dividindo-se em três seções principais:
1. **Início (Home):** Apresentação do conceito do projeto com cards informativos interativos.
2. **O Equilíbrio (Sobre):** Seção detalhada sobre manejo integrado, agricultura de precisão e rotação de culturas, utilizando um sistema de expansão de conteúdo.
3. **Simulador Eco:** Um mini-aplicativo web interativo onde o produtor ou visitante pode ajustar o tamanho de uma propriedade rural e ativar tecnologias para calcular, em tempo real, o impacto ecológico positivo (água economizada e CO₂ evitado).

---

## 🛠️ Tecnologias e Códigos Utilizados

O projeto foi construído do zero utilizando tecnologias nativas da web, priorizando um código limpo, sem dependências externas e focado em performance:

### 1. HTML5 (Estrutura)
* **Semântica Avançada:** Uso de tags estruturais como `<header>`, `<main>`, `<section>` e `<footer>` para garantir acessibilidade e melhor indexação (SEO).
* **Arquitetura Multipáginas:** Separação modular de arquivos (`index.html`, `sobre.html`, `simulador.html`) com navegação fluida entre os menus.
* **Elementos de Entrada:** Utilização de inputs modernos, como o tipo `range` (barra deslizante) e `checkboxes` para alimentar o simulador.

### 2. CSS3 (Design e Estilização)
* **Identidade Visual Temática:** Paleta de cores baseada em tons de verde oliva, floresta e tons claros, conectando o usuário visualmente ao tema da terra e da tecnologia limpa.
* **Layout Responsivo:** Implementação de **CSS Grid** e **Flexbox**, garantindo que o layout e as tabelas de dados se adaptem perfeitamente a computadores, tablets e smartphones.
* **Efeitos Visuais:** Microinterações suaves através de `transitions` e `hovers` nos botões, links de navegação e cards de conteúdo.

### 3. JavaScript (Interatividade Dinâmica)
* **Manipulação do DOM:** Gerenciamento de eventos de clique e mudança (`click` e `change`) para atualizar o conteúdo da tela em tempo real sem a necessidade de recarregar a página.
* **Efeito Accordion (Sanfona):** Lógica que calcula a propriedade `scrollHeight` para abrir e fechar os tópicos informativos com transições suaves.
* **Algoritmo do Simulador:** Lógica matemática aplicada para calcular projeções ecológicas instantâneas com base nos dados fornecidos pelo usuário via interface.

## 🚀 Como Executar o Projeto Localmente

1. Clone este repositório ou baixe os arquivos.
2. Abra a pasta do projeto no **VS Code**.
3. Certifique-se de ter a extensão **Live Server** instalada.
4. Clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server**.
